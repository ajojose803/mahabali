# Mahabali E-commerce Platform

Mahabali is a robust, feature-rich e-commerce platform built using Node.js and Express.js, designed to cater to the needs of admins, vendors, and users. It includes a fully functional admin dashboard, user-friendly interfaces for customers, and efficient tools for vendor management.

---

## Features

### Admin Module
- **Dashboard**: Monitor platform performance with real-time insights.
- **User Management**: Search, block, and manage users with detailed stats.
- **Product Management**: Add, update, or remove products and categories.
- **Order Management**: Track, process, and manage customer orders.
- **Coupon Management**: Create and manage promotional coupons.

### User Module
- **User Authentication**: Secure login, signup, and OTP verification.
- **Product Browsing**: Explore a wide range of categories and products.
- **Shopping Cart**: Add products to the cart and proceed to checkout.
- **Wishlist**: Save products for later.
- **Order History**: View previous purchases and their status.

---

## Technologies Used

- **Backend**: Node.js, Express.js
- **Frontend**: HTML, CSS, JavaScript, EJS
- **Database**: MongoDB
- **Logging**: Winston, Morgan
- **Containerization**: Docker
- **Orchestration**: Kubernetes

## Setup Instructions

### Prerequisites
- Node.js
- Docker
- Kubernetes CLI (kubectl)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ajojose803/mahabali.git
   cd mahabali

2. Install dependencies:
    ```bash
    npm install

3. Set up the environment:
    Copy the .env.example file to .env and update the configuration values.

4. Start the application:
    ```bash
     npm start
